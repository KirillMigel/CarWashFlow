# CarWashFlow

SwiftUI-прототип для iOS 26 по макетам Figma.

## Флоу

1. На главном экране нажмите «Пора помыть авто».
2. Перетаскивайте тряпку по всей машине. След движения постепенно открывает чистое изображение автомобиля.
3. Финальный экран и кнопка «Заглянуть в автомойки» появляются только после очистки всего силуэта автомобиля; по чистой машине один раз проходит shine, вокруг появляются звёздочки, после чего остаётся мягкое постоянное пульсирующее свечение.
4. Кнопка открывает экран карты автомоек.

Тряпка отрисовывается через Metal cloth simulation из предоставленного `Paper.zip`; её текстура, автомобили и экран карты взяты из макета. Главный экран использует Figma-фрейм `6306:194530` в вариантах 1×/2×/3×, верхняя иконка автомобиля — предоставленный `transport-auto.png`, а нижняя навигация — предоставленный `MB.png`. Все экраны до карты используют единый тёмный фон первого экрана.

## Запуск

- Откройте `CarWashFlow.xcodeproj` в Xcode 26.
- Выберите iPhone с iOS 26 и запустите схему `CarWashFlow`.

Проект не использует внешние зависимости.
